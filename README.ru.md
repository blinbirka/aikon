# Aikon

Отображение статусов сессий AI внутри редактора. Сейчас работает с Claude Code
и редакторами семейства VS Code.

![Aikon в меню-баре](docs/screenshot.png)

Каждая папка с сессией видна в меню: статус и сколько прошло с последней записи.
Клик по строке поднимает окно редактора с этой папкой.

## Установка

1. Скачай архив из [релизов](../../releases), распакуй, перетащи **Aikon**
   в «Программы».
2. Aikon подписывает сам себя, ad-hoc: сертификата Apple за этой подписью нет,
   и у Apple он не заверен. Поэтому macOS один раз переспросит. Одна строка
   в терминале, работает на любой версии:

   ```sh
   xattr -cr /Applications/Aikon.app
   ```

   Без терминала: на **macOS 14** — правый клик по Aikon, *Открыть*, потом
   *Открыть* ещё раз. На **macOS 15 и новее** — двойной клик, закрыть
   предупреждение, потом *Системные настройки → Конфиденциальность
   и безопасность → Всё равно открыть*.
3. Запусти Aikon. Иконки в доке у него нет, ищи в строке меню.
4. Открой **Настройки → Хук статусов → Установить**.

Четвёртый шаг отличает «Claude занят» от «Claude что-то спросил и стоит». Хук
добавляет несколько записей в `~/.claude/settings.json`, перед этим делает
резервную копию и не трогает твои остальные хуки. Убирается там же, где
ставится.

## Что читает

Транскрипты сессий из папки, указанной в настройках (по умолчанию
`~/.claude/projects`), и список открытых папок редактора. Оба файла и так лежат
на диске. Из транскрипта читается только рабочая папка и причина, по которой
сессия остановилась, сама переписка — никогда.

Aikon делает один сетевой запрос: к GitHub, не чаще раза в три дня, чтобы
проверить новую версию. Выключи это в настройках — и запросов не будет вообще.
Больше ничего наружу не уходит: ни аналитики, ни имён проектов, ни текста
сессий.

## Требования

macOS 14 и новее, Apple Silicon или Intel — для приложения из релизов. Чтобы
собрать самому, нужен ещё Xcode 16 или новее, с macOS 14 он не идёт.
Claude Code. Редактор семейства
VS Code: VS Code, Cursor, Windsurf или VSCodium. Каждый из них хранит описание
самого себя, Aikon его читает и подхватывает те, что у тебя стоят.

Zed и IDE от JetBrains хранят список открытых окон по-своему, под них нужен
отдельный кусок кода. Если хочешь помочь, загляни в открытую задачу.

## Лимиты

В меню может показываться, сколько израсходовано от пятичасового и недельного
лимитов Claude. Сам Aikon это не считает: он читает файл
`~/.claude/tools/notify/state/limits`, если его пишет что-то ещё на твоей
машине. Одна строка: `израсходовано5ч израсходовано7д когдаЗаписано
сброс5ч сброс7д`, доли — дробью, время сброса — в секундах unix. Нет файла —
нет блока в меню.

## Сборка из исходников

```sh
bash scripts/install.sh
```

Соберёт универсальное приложение, подпишет и положит в «Программы». Нужен
Swift 6, он идёт с Xcode 16 и новее. Зависимостей нет. Собранное приложение
весит около 3,5 МБ, архив в релизе — около 1 МБ.

Если отдаёшь репозиторий агенту: в корне лежит `CLAUDE.md` с командами
и правилами проекта.
