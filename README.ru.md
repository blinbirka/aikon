# Aikon

Отображение статусов сессий AI внутри IDE. Сейчас работает с Claude в VS Code.

![Aikon в меню-баре](docs/screenshot.png)

Каждая папка с сессией видна в меню: статус и сколько прошло с последней записи.
Клик по строке поднимает окно VS Code с этой папкой.

## Установка

1. Скачай `Aikon.zip` из [релизов](../../releases), распакуй, перетащи **Aikon**
   в «Программы».
2. macOS скажет, что приложение повреждено или от неизвестного разработчика.
   Сними карантин:

   ```sh
   xattr -cr /Applications/Aikon.app
   ```

3. Запусти Aikon и открой **Настройки → Хук статусов → Установить**.

Третий шаг отличает «Claude занят» от «Claude что-то спросил и стоит». Хук
дописывает одну строку в `~/.claude/settings.json`, перед этим делает резервную
копию и не трогает твои остальные хуки. Убирается там же, где ставится.

## Что читает

Транскрипты сессий из папки, указанной в настройках (по умолчанию
`~/.claude/projects`), и список открытых папок VS Code. Оба файла и так лежат
на диске.

Aikon делает один сетевой запрос: к GitHub, не чаще раза в три дня, чтобы
проверить новую версию. Выключи это в настройках — и запросов не будет вообще.
Больше ничего наружу не уходит: ни аналитики, ни имён проектов, ни текста
сессий.

## Требования

macOS 14 и новее, VS Code, Claude Code.

Пока только VS Code. Cursor, Zed и JetBrains хранят список открытых окон
каждый по-своему, под каждый нужен свой кусок кода. Если хочешь помочь,
загляни в открытую задачу.

## Сборка из исходников

```sh
swift build -c release
bash scripts/install.sh
```

Зависимостей нет, собранное приложение весит около 2 МБ.
